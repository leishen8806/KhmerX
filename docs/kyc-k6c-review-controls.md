# K6c：员工审核交互（R8 / R9 / R10）

依赖 K4 PR #87，基线 `5f610954163a37280660f1cac23887ad19aacafa`。

- 跟进面板仅链接审核详情，不预选通过结果。
- 代修改字段高亮；保存前列出原值与新值，必须确认差异和原因。字段值或原因变化后，原确认不能用于保存新的内容。原有服务端字段权限、原因、版本和客户确认规则继续生效。
- 证件号码、银行账号默认仅显示末四位；审核员可主动显示、再次隐藏。切换资料或版本后恢复脱敏。此措施控制页面展示，原始资料仍通过现有授权接口送达审核浏览器，不等同于接口级脱敏。
- 本批没有新增查看审计、服务端写入或审计接口。“显示”只改变本地页面展示，未记录查看事件。若需记录每次查看，必须补充服务端支持：**涉及审计，需评审**。
- 代修改模式的输入框和差异确认会展示本次需要修改的原始值。原文、审核意见及客户资料不经过翻译。
- 新增显示/隐藏与差异确认文案提供 zh / en / km；既有员工代修改表单仍有中文文案，高棉语质量待母语复核。

禁止在本批合并时宣称已完成敏感字段查看审计。无部署、线上写入、迁移、认证或资金逻辑变更。
