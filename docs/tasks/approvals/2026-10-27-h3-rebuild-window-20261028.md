- **建议的只读核对(只输出三个标签,不会打印环境变量):**
  ```bash
  docker inspect gray-payease-1 --format '{{index .Config.Labels "com.docker.compose.project"}} | {{index .Config.Labels "com.docker.compose.project.config_files"}} | {{index .Config.Labels "com.docker.compose.project.working_dir"}}'
  ```
