# 决定:灰度窗口接受无异地备份(H2 / D6)

决定日期:2026-10-27。技术负责人原话:"H2 接受无异地备份"。由负责人在本对话中明确回复,Claude 据此记录。
来源:`docs/tasks/rebaseline-v3-20261027.md` §5 H2;`docs/tasks/status/2026-10-27-o2-provenance-fix-runsheet.md` §2 第 4 项、§3"备份"一行(选项二)。

## 决定的内容
- 在 v3 计划的灰度窗口(O2 重建窗口、W1、W2)中,**不要求**使用 `backup.sh --apply` 的异地(Spaces)备份,即接受"本次灰度窗口无异地备份"。
- 因此 D6(Spaces 备份配置)**不再是这些窗口的前置条件**。O2 执行单 §2 第 4 项视为已处理。

## 这个决定是什么、不是什么
- **它是对 `decision-log.md` D-11("备份放不同区域")和 `master-plan-20261015.md` §12.3a 中"每日备份到异地对象存储"在灰度阶段的例外。** 生产或灰度转正式使用前,异地备份不能沿用这个例外,需要重新决定。
- **它没有取消窗口自带的本机备份。** `L1-G-gray-fixture.md` §7 的窗口流程在停机后、写入前后各做一次本机备份(`d1-before-<runId>.tgz`、`d1-after-<runId>.tgz`),`l2-gate-a-window-checklist.md` 的回退依赖 `d1-before`。这些本机备份仍然是 W1/W2 的必做步骤,不受本决定影响。
- 灰度只使用虚构数据(D-02),且已接受单点风险(D-03);无异地备份意味着**机器或磁盘整体损坏时无法从异地恢复**,只能重建环境。
- 它不批准任何窗口,不批准重建、W1 或 W2,不改变灰度、VPS、L2/Q12 的 HOLD。

## 对 v3 的影响
- "备份与恢复演练"只能是**本机备份的恢复演练**(从本机备份还原),不能证明异地恢复。v3 的档位 1 和档位 3 里对应的表述相应收窄。
- 不再需要等 Spaces 配置;H3(重建窗口)的前置条件少了一项。

## 待负责人回复的一点(不阻塞本决定)
O2 重建窗口本身不改数据目录,窗口自带的本机备份流程是 W1/W2 的流程。**重建窗口前,是否要求对 `/opt/payease/data` 先做一次本机副本(应用停机后复制)?** Claude 的建议是做,成本低、可以回退;但这是负责人的决定,未回复前不要求、也不得由 OPS 自行改动数据目录。
