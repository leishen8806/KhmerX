## 本次运行直接暴露的 4 个问题
1. 第一屏仍是"服务机构"选择流程，和已冻结的公共认证方案不一致。
2. 401 提示显示为原始键名 `error.auth.unauthenticated`（没有对应的多语言文案，用户看到的是代码）。
3. 登录页直接显示内部公司 ID 和"更换服务机构"。
4. 无法在本机登录：APP 把后端当"浏览器客户端"，但本地 dev 服务需要网关注入身份才放行，缺一个能给 APP 用的本地后端环境。

## 下一步（第 1 阶段范围：登录、首页、合同只读）
1. 去掉服务机构选择流程，改为公共登录入口。
2. 401/`AUTH_REQUIRED` 映射为"请重新登录"，并接上会话失效回调。
3. 未翻译键名兜底为通用提示，不暴露代码。
4. 搭好本地测试后端（含测试租户和测试账号），实机走通 登录 → 首页 → 贷款合同只读。
5. 发布配置：`APP_ENV` 默认值、release 签名。
