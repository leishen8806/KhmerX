# Telegram 设备端 UI 与流程验收记录（2026-10-19）

## 验收范围

- 设备：Telegram Desktop，KhmerXBot WebApp
- 页面：首页、借款进度、借款记录、借款详情、我的、实名资料
- 检查项：真实点击链路、页面层级、卡片与间距、底部导航、状态文案、按钮可读性和流程回退
- 数据：既有 UAT 合成资料与测试借款（测试资金，不产生真实债务）

## 已完成的设备验收

1. 首页加载成功，当前借款金额、机构审批状态、身份资料入口和三步提示可见。
2. 点击“查看借款进度”进入详情，金额、期限、账单、时间线和返回链路可用。
3. “借款记录”可进入列表，点击借款卡片可回到同一笔借款详情。
4. “我的”页面可打开，账户、公司、身份状态、借款记录、账户安全、提醒和退出入口布局统一。
5. 实名资料页可打开，顶部返回、通过提示、分组卡片和底部导航均可见；页面使用统一圆角卡片、蓝色主操作和固定底部导航。

## 上线前阻断条件

生产发布完成后必须在同一 Telegram 设备重新打开 WebApp，确认：

1. 实名资料通过时六个分组均显示绿色“已完成”；
2. “开始贷款申请”按钮为蓝色、文字清晰且可点击；
3. 首页 → 借款进度 → 借款记录 → 我的 → 实名资料的往返链路无错误；
4. 生产 API 与数据库写回仍对应同一测试租户和合成借款；
5. 生产域名版本与测试站版本一致后，才可将本次修复标记为上线完成。
