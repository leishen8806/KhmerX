# KhmerX 后台正式上线实施与验收清单

版本：2026-10-06  
基线：业务后台管理产品需求方案 v1.1  
范围：金融服务机构后台、持牌机构后台、开放 API 控制台

## 一、上线结论

当前版本已完成测试资金下的核心贷款闭环和基础 CRM 工作台，但尚未达到正式金融生产上线标准。当前可验收范围为：员工登录、公司与部门隔离、KYC 队列、贷款申请、机构审批、签约、测试放款、账单、测试还款、贷后任务、通知配置、基础权限和审计。

真实资金、真实支付/银行、持牌机构独立服务器 API、生产 Bot 多渠道切换、外部不可变审计归档、完整报表、客服工单和 Break-glass 应急流程，必须完成后续阶段并单独签字验收。

## 二、分阶段实施

### 阶段 0：发布基线与回滚

验收标准：

- 本地构建成功，自动化测试无失败；
- 发布前保存代码版本、镜像摘要、数据库迁移状态和数据备份；
- `khmerx.org`、`payease.khmerx.org`、`admin.khmerx.org`、`api.khmerx.org` 均完成外部访问验证；
- Caddy/Nginx 只负责 TLS、路由和基础限制，不承担业务授权；
- 发布失败可恢复上一镜像和数据库备份。

当前状态：已完成测试部署验证；生产资金门禁仍保持开启。

### 阶段 1：V1 核心业务闭环

范围：

- 员工登录、公司/部门/角色和数据范围；
- KYC 提交、审核、补件、拒绝和重新提交；
- 贷款申请、机构审批、复核、费用确认和签约；
- 测试放款、账单、测试还款和结清；
- 贷后任务、逾期任务和基础 Telegram 通知；
- 基础操作审计和幂等校验。

验收重点：同一员工不能完成审批与复核/放款；重复放款或还款不能重复入账；历史账单不受费率修改影响。

当前状态：代码测试通过，需继续按角色进行线上 UI、网络请求和数据回读验收。

### 阶段 2：运营可用能力

范围：

- 客户列表与客户 360° 详情；
- 统一搜索：用户 ID、用户名称、身份证末四位、手机号掩码、申请编号、Loan ID、流水号和工单号；
- 字段级 KYC 修改权限、前后值审计和二次复核；
- 补件任务、客服工单、投诉与争议；
- 产品与费率草稿、复核、生效、废止和历史快照；
- 三语通知模板、失败重试、失败原因和发送记录；
- 运营漏斗、KYC/审批、放还款、逾期和客服报表；
- 脱敏导出与导出审计。

当前状态：客户列表与脱敏客户 360 已形成闭环；运营数据摘要已上线并按员工数据范围计算，并已加入业务队列和左侧菜单入口。脱敏客户摘要 CSV 已支持按员工数据范围导出，并写入 `report_export` 审计记录。KYC 字段级授权已形成闭环：Admin 可按身份、联系人、工作收入、银行钱包、地址定位单独授予权限；审核员代修改会校验授权、保存掩码前后值审计，并强制客户重新提交。通知模板管理已形成三语模板的版本化保存、启停和审计接口及后台入口，贷后 Telegram 发送会按客户语言读取 `repayment_reminder` 模板，并在未配置时安全回退默认文案。客服工单、投诉与争议已支持公司隔离建单、处理、状态流转和审计。报表导出已补齐 KYC/审批、放款/还款、逾期催收三类脱敏 CSV，后台已增加报表类型选择器，并沿用员工数据范围与导出审计。统一搜索目前覆盖客户 ID、脱敏手机号、KYC 编号和 Loan ID。`team_audit` 已增加数据库级追加-only 触发器，业务路径不能更新或删除既有审计记录；这属于数据库层保护，不等同于外部不可变归档或哈希链。

### 阶段 3：生产金融能力

范围：

- 持牌机构独立服务器和独立数据库/文件边界；
- 签名 API、回调验签、IP 白名单、Nonce、防重放、幂等键和死信队列；
- 真实支付/银行适配层、对账、冲正、退款和资金隔离；
- 每日 10,000 USD、每月 30,000 USD 放款限额；
- 监管余额 20% 风险事件、告警、冻结和双人解除；
- 生产逾期定时任务、规则快照和黑名单策略；
- Bot 多渠道真实发送、切换和故障告警。

当前状态：已完成测试资金放款前的日/月额度门禁（每日 10,000 USD、每月 30,000 USD）及剩余额度 20% 预警计算，员工放款与 Admin 应急放款路径统一返回机器可读的超限错误码；已增加持牌机构回调的签名、时间窗口、nonce 防重放、幂等回执表和 `received` 接收状态，但尚未绑定真实机构密钥或驱动业务状态变更。真实资金、持牌机构生产接口和支付回调仍未验收，禁止打开真实放款。

补充部署决策（2026-10-06）：持牌机构后台本阶段暂与金融服务机构共用当前 VPS、数据库和 `admin.khmerx.org` 登录域名；登录页提供“服务机构后台／持牌机构后台”入口切换。持牌机构入口目前只允许机构复核员、放款复核员，机构审批员和放款员不得通过该入口登录；其他服务机构岗位也不能进入持牌机构入口。持牌机构登录后的左侧菜单仅显示贷款复核或放款复核、审计记录；服务机构登录显示服务机构工作台菜单。入口模式写入独立会话标识，数据仍按公司、机构和岗位范围隔离。后续迁移到独立服务器时保留相同入口协议、机构标识、API 边界和数据库迁移，不复用服务机构后台会话或直接放开跨机构数据访问。

### 阶段 4：安全与合规上线

范围：

- 管理员 MFA、账号回收、会话撤销和密码版本失效；
- 文件 10MB 限制在浏览器、代理、API、扫描器和存储层一致；
- 图片/PDF 文件头、MIME、扩展名、病毒扫描、重复上传和对象隔离；
- 审计不可变归档、哈希链/归档校验、留存和脱敏导出；
- Break-glass 应急权限默认 30 分钟、指定对象和动作、双人复核、自动失效；
- 备份恢复演练、5xx/502 告警、漏洞修复和回滚演练。

当前状态：ClamAV 网关和基础审计已接入；数据库级追加-only 审计保护和 SHA-256 审计快照校验已接入，Admin 已可按员工撤销全部后台会话并记录原因；管理员 MFA 已支持加密密钥设置、SSO/密码登录二次验证、一次性恢复码和审计；浏览器、KYC API、贷款签名 API、ClamAV 网关已统一使用 10MB 文件上限，代理层保持 10MB 限制并完成构建/静态一致性检查；Break-glass 已实现双 Admin 请求/批准、30 分钟过期、撤销和审计管理，并已接入 Admin 测试资金操作的 funding 范围授权校验（默认业务路径不受影响）；外部不可变审计归档和灾备演练尚未完成。

## 三、正式验收门槛

以下任一项未通过，不得标记为正式金融生产上线：

1. 生产仍允许 demo 登录、测试账号或测试资金；
2. 线上无法完成 Mini App、H5、后台三套身份隔离验证；
3. KYC 关键字段修改没有字段权限、前后值、原因和复核记录；
4. 文件上传限制和病毒扫描在任一层不一致；
5. 放款限额、监管预警、冻结解除没有事务内检查和风险事件；
6. 持牌机构接口没有回调验签、幂等、防重放和失败队列；
7. 审计记录可被普通员工覆盖、删除或导出未脱敏数据；
8. 未完成数据备份恢复和回滚演练。

## 五、验收证据要求

每个阶段必须同时保存：

- 页面操作记录；
- 网络请求和响应状态；
- 服务端数据库写入后回读；
- 权限拒绝和越权测试结果；
- 审计记录、request ID 和关联业务编号；
- 发布镜像、迁移、容器健康和外部域名验证结果。

只有“页面显示成功”而没有服务端数据变化、权限证据或审计记录，不计入验收通过。
