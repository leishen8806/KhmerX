# CRM 二级菜单操作能力核查（2026-10-08）

## 判定口径

- **新增**：页面有新增入口，并调用受权限保护的服务端写入动作。
- **编辑/修改**：页面可修改业务字段、状态或配置，并要求版本/原因（如适用）。
- **查询**：页面可按授权范围读取，并支持页面内筛选。
- **导出**：优先使用服务端脱敏、审计导出；普通数据视图提供当前筛选结果 CSV 快照。
- “无新增”不一定是缺陷：审计、报表、流水等记录型页面不应直接新增业务数据。

## 仍需产品确认或后续开发

以下项目目前是“查询/导出”或复用现有主工作台能力，尚未在独立二级页面完成完整新增/编辑闭环：

1. **合同与签约、提现与钱包、业务时间线**：独立页目前以查询/导出为主；签约由客户端完成，钱包/提现需要明确真实支付接口和复核流程后再开放写入。
2. **风控事件、资金监管、每日/月放款限额、20% 资金预警、冻结与解除、资金流水、对账异常**：当前独立页查询和导出；限额配置、预警确认、冻结/解除和异常关闭需要独立动作组件及对应审计字段。
3. **贷款产品、风控规则与版本、公司新闻、行业资讯、帮助中心**：当前为配置/记录查询入口；需要明确产品版本、发布、下线、草稿和审批规则后再开放写入，避免把内容编辑误接到通用事件表。
4. **数据范围、字段权限、持牌机构、API 应用、语言与时区、文件与扫描配置、系统健康**：部分能力已有主页面或后端接口，但独立页仍偏查询；下一阶段应逐项接入真实配置表单和回读验证。
5. **客户标签与分组**：客户 360° 查询已具备，标签/分组的新增、编辑、合并、批量导入规则尚需产品确认。

## 验收要求

每个具备写入的页面至少验证：

1. 正常新增/编辑/修改后，界面刷新仍显示新值；
2. 浏览器网络请求返回成功且包含机器可读 `code`（如失败不得只依赖中文字符串）；
3. 服务端数据库回读与页面一致；
4. 越权公司、越权岗位、过期版本、重复提交均被拒绝；
5. 关键动作产生审计记录；
6. 查询条件、清空条件、重新进入页面和导出结果保持一致；
7. 导出不包含未授权字段，文件名包含页面标识，CSV 可正常打开。
