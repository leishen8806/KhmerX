# 放款、还款与催收承接

公司 Admin 在工作台配置放款机构、还款机构和贷后承接部门。自动分配开启时，新客户分单及尚无承接信息的历史分单自动补齐；修改默认配置不会覆盖已有承接记录。贷款审批机构仍由原机构分单独立管理。

本次迁移为已有公司建立放款承接机构、还款承接机构，并使用运营贷后部承接催收；默认开启自动分配。新增公司的 Admin 可以先新增机构及贷后部门，再保存承接配置。

## 权限和资金操作
- 普通放款岗位按指定放款机构访问订单，保留发起与独立复核。
- Admin 可以直接确认本公司已完成初审、复核及签约的测试贷款放款；不能跳过贷款审批和 KYC 校验。
- Admin 登记测试还款须填写金额、唯一流水号及依据；支持部分和全额还款。重复流水相同贷款与金额不会再次入账，不同金额或订单则拒绝。
- Admin 可以查看本公司全部催收任务、添加处理记录及改派。客服仍仅访问所属部门分配给自己的任务。
- 所有资金操作校验公司、当前角色版本、分单版本和订单版本，使用同一事务写入账本、流水及审计。

## 贷后
到期任务优先使用客户指定的催收承接部门，在该部门内按客服待办量分配。没有可用客服保留待分配，Admin 可处理。关闭自动分配不删除已有任务；还款结清自动关闭任务。已有贷款审批、合同、费率和资金记录不因修改默认承接配置而重写。

当前所有放款与还款仍为测试资金，不调用真实银行通道。
