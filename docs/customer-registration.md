# 手机号注册与渠道必需设置

客户输入含国家区号的手机号后自动创建公司内客户账号，并建立当前浏览器会话。后台渠道开启的手机号验证和密码设置必须完成；关闭的项目不展示、不拦截。未验证手机号保持未验证，不计入 KYC 手机号验证分值。

已有账号不能由另一浏览器仅凭手机号进入；需要验证码或已设置的密码。同一注册浏览器可继续，退出登录会取消该浏览器的手机号恢复权限。会话与浏览器凭据有效期为 24 小时，均使用 HttpOnly Cookie。跳过验证和密码后若退出或丢失会话，需要完成验证码验证才能恢复。

密码以独立随机盐和 PBKDF2-SHA256 保存，不保存明文；密码登录有账号、浏览器和公司级尝试限制。设置密码不会使手机号变为已验证。更改已有密码需当前密码，并撤销其他客户会话。

第一次真实手机号验证保留客户编号，同时撤销此前未验证的会话、浏览器恢复权限和密码，以免提前注册该号码的人继续访问。现有历史账号不允许由纯手机号注册领取。

Telegram Gateway 未配置时仍可注册；只有关闭手机号验证的渠道才不要求完成验证；当前 demo 模式的验证码仅适用于预留合成号码，模拟验证码不代表真实手机号验证。客户会话不授予员工权限。

## 业务渠道开关
公司 Admin 在“Telegram 业务渠道”分别开启／关闭手机号验证、设置密码，默认均开启且必须完成。全部关闭时注册后直接进入申请。账号记录注册时的渠道，后续切换默认业务机器人不改变已有账号归属；该账号的必需步骤遵循其注册渠道的最新设置。后端拒绝调用已关闭的设置步骤，并拦截尚未完成必需设置的客户业务与 KYC 请求，已有账号的验证码／密码登录仍保留。

测试模式的模拟验证码完成状态与真实手机号验证状态分别保存：模拟验证可满足测试渠道步骤，但不计作 KYC 真实手机号已验证。

## 忘记密码与手机号找回
登录页和账号设置提供“忘记密码”。输入注册手机号并同意接收验证码，填写本次重置验证码与两次新密码（12–128 字符），验证通过后重置并返回密码登录。无需旧密码；后台注册验证／设置密码开关不会关闭已有账号的找回入口。

重置验证码与普通登录验证码用途隔离，绑定公司、浏览器、运行模式，5 分钟有效、最多核验 5 次、一次性消费。发码和重置均限流。核验成功后才判断账号是否存在，不通过此流程创建新账号。密码使用独立随机盐保存哈希。密码与会话版本在同次更新中修改，所有旧会话立即失效，旧浏览器恢复权限取消。真实发送失败不会降级为模拟验证。

当前仍为 demo 模式，仅预留测试号码可完成模拟找回；真实 +855 号码找回需 Telegram Gateway 开通并切换正式验证码模式。
