# 手机号注册与可选安全设置

客户输入含国家区号的手机号后自动创建公司内客户账号，并建立当前浏览器会话。手机号验证和密码设置均可跳过，后续从“账号设置”补充。未验证手机号保持未验证，不计入 KYC 手机号验证分值。

已有账号不能由另一浏览器仅凭手机号进入；需要验证码或已设置的密码。同一注册浏览器可继续，退出登录会取消该浏览器的手机号恢复权限。会话与浏览器凭据有效期为 24 小时，均使用 HttpOnly Cookie。跳过验证和密码后若退出或丢失会话，需要完成验证码验证才能恢复。

密码以独立随机盐和 PBKDF2-SHA256 保存，不保存明文；密码登录有账号、浏览器和公司级尝试限制。设置密码不会使手机号变为已验证。更改已有密码需当前密码，并撤销其他客户会话。

第一次真实手机号验证保留客户编号，同时撤销此前未验证的会话、浏览器恢复权限和密码，以免提前注册该号码的人继续访问。现有历史账号不允许由纯手机号注册领取。

Telegram Gateway 未配置时仍可注册和跳过；当前 demo 模式的验证码仅适用于预留合成号码，模拟验证码不代表真实手机号验证。客户会话不授予员工权限。

## 业务渠道开关
公司 Admin 在“Telegram 业务渠道”分别开启／关闭手机号验证、设置密码，默认均开启且允许跳过。全部关闭时注册后直接进入申请。账号记录注册时的渠道，后续切换默认业务机器人不改变已有账号归属；该账号的可选步骤遵循其注册渠道的最新设置。后端拒绝调用已关闭的设置步骤，已有账号的验证码／密码登录仍保留。
