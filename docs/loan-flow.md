# KYC 与贷款申请分离

注册／账号设置 → 独立填写 KYC → 运营人工审核通过 → 选择贷款金额与期限 → 测算并确认费用 → 独立手写签约 → 机构审批及独立复核 → 放款。

KYC 阶段只提交身份资料与资料审核授权，不要求金额、期限、借款协议或手写签名。审核未通过时，客户端不展示金额申请表，服务端也拒绝创建贷款。补件和拒绝仍按资料审核流程处理。

新申请绑定已通过的 KYC 版本。客户确认费用后在独立签约页签署本笔借款协议；签名与合同绑定本笔申请、费用及已审核资料，不修改 KYC 版本或材料。签约完成后才能提交贷款审批。机构审批与放款仍保留岗位分离、双人复核。

历史已创建贷款可以继续完成 KYC 后申请；历史合同保持原快照。单账号旧演示入口保留原演示兼容，H5 客户与公司业务使用上述主线。
