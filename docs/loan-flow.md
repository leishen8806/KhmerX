# 客户贷款主线

贷款申请 → 测算费用 → 用户确认签约 → 贷款审批 → 放款。

客户完成账号所需设置后，选择金额及 14／28 天期限创建申请。服务端保存后台费率测算账单；客户确认该账单后，完善 KYC 资料并在最后环节手写签约。未确认费用不能生成新签名合同。

资料经人工审核后，客户提交已签合同进入机构贷款审批。送审和机构初审均核对当前申请、账单、签名、资料版本；签约未完成不能送审或审批。机构独立复核通过后按已签合同进入待放款，再由放款员发起、另一员工复核放款。提现、还款和贷后处理沿用现有流程。

适用于 H5 客户及公司协作业务；单账号旧演示入口保留原演示状态兼容。历史已生成合同不重新签署，未审批申请仍需有效的费用确认与签名证明。
