## 四、验收结论

### 已通过

- 隔离 UAT 合成数据的组织、权限、认证、KYC、审批、签约、放款、账单、还款、结清、审计和退出闭环。
- 服务端数据回读、状态机、幂等键、权限拒绝、跨公司隔离和审计证据均由自动化测试覆盖。
- 当前部署版本页面、菜单、组织架构说明、默认公司文案和头像入口已完成浏览器复测。

### 未完成/放行阻塞

共享线上租户没有可持久化的公司/订单合成数据，无法做真实浏览器写入回放。因此以下项目不能标记为线上闭环通过：

- 创建两家公司并在刷新后仍可见；
- 平台管理员设置默认公司；
- 头像菜单切换公司后数据范围、页面标题和 API 回读随公司变化；
- 客户端提交 KYC、后台审核通过/退回、贷款到签约、放款到账单、还款结清的线上双端写回。

这不是自动化业务逻辑失败，而是共享租户缺少专用 UAT seed/replay 数据能力。生产放行前必须在专用 UAT 租户执行一次 `seed → 客户端提交 → 后台审核/退回 → 审批/复核 → 签约 → 放款 → 账单 → 部分/全额还款 → 审计导出 → purge`，并保存订单号、Loan ID、request ID、审计记录和刷新后的数据库回读证据。
