# 最终业务数据闭环 UAT 工作任务与执行记录

## 目标

在不污染共享生产数据的前提下，证明以下链路可重复、可隔离、可审计：

`公司/机构 → 员工认证 → KYC → 贷款审批 → 双人复核 → 放款 → 账单 → 还款 → 结清 → 贷后 → 审计`

## 发布门槛

当前允许发布的范围是“隔离 UAT 闭环 + 生产控制面 + 默认关闭的受控 UAT 入口”。在明确启用开关和令牌前，不允许把合成 KYC、贷款、账单写入共享生产租户，也不允许用临时 SQL 或未审计脚本清理。受控入口满足：

1. 仅平台管理员可执行，且仅允许专用 `uat-*` 租户；
2. `batchId` 与幂等键必填，重复执行返回同一批次结果；
3. seed、推进、清理均写入 `team_audit`；
4. 清理前执行版本/CAS 校验，清理后回读关键表和业务状态为零；
5. 入口上线后，按 UAT-01 至 UAT-09 重新执行浏览器、接口和服务端数据回读。

## 当前结论

业务逻辑闭环已由隔离 UAT 通过；生产业务数据闭环尚未宣称完成，唯一原因是缺少可审计、可回滚、可重复的生产 UAT 数据入口。该边界已记录，后续开发应先完成 UAT-10，再进行线上业务数据复放验收。
