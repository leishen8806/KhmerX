# 员工登录与退出

业务登录入口 `/team/login`，使用公司入口代码、员工邮箱和独立随机密码。站点保持私有访问验证；员工密码不授予站点访问权。

Admin 创建员工时默认启用独立密码登录，创建成功后一次性下载账号文件。密码仅保存 PBKDF2-SHA256 盐化摘要。未启用时沿用已有站点身份匹配。独立账号不会根据同邮箱自动获得其他公司的权限。

公司 Admin 可在“员工与权限”中为其他启用中的员工重置密码。重置必须填写原因；系统生成新的随机密码、递增密码版本使旧会话和旧密码立即失效，并仅在当前页面一次性提供下载。不能重置自己的密码或已停用员工的密码。

员工会话有效期 8 小时，绑定站点访问身份、员工权限版本及密码版本。停用或修改员工权限使既有会话失效。登录按账号及访问身份限制 15 分钟窗口尝试次数。密码、会话令牌不进入审计记录。

退出撤销服务端会话并阻止自动回退到站点 Admin。返回公司选择仅离开当前工作区，不等同退出。恢复站点员工身份需显式点击登录页的对应按钮。

客户使用原客户公司 cookie，后台使用独立公司 cookie。后台换公司或退出不改变客户所属公司。旧后台会话在首次切换前兼容原公司选择。

0014 迁移仅为现有联调测试公司 B 创建 UAT 测试审批机构及 lender/checker 两个独立账号，不提升 Admin 审批权限，不更改现有订单分配。随机密码已单独导出本机，不包含在代码仓库。其他环境只建立表结构。

0015 为现有 A/B 公司 Admin 开启密码登录，保留原成员身份及公司权限。密码会话只授予登录公司范围；同一邮箱的另一公司必须单独验证密码。平台管理继续使用明确选择的站点身份。
